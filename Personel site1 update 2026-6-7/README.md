🚀 Sadra | Personal Portfolio
📌 Overview

A modern, responsive, and bilingual personal portfolio website designed to showcase my projects, skills, and development journey.

Built with a focus on performance, clean structure, and user experience without relying on external frameworks.

🧩 Features
🌍 Bilingual system (English / Persian)
🎨 Theme customization (multiple styles)
📱 Fully responsive design
⚡ Fast and lightweight
🗂️ Project showcase with filtering
🔗 Social and contact integration
🧠 Smooth UI interactions
🛠️ Tech Stack

HTML5 • CSS3 • JavaScript • LocalStorage • Google Fonts
